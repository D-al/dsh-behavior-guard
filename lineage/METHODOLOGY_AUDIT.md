# 方法论自审：决策链方法本身科学吗？有证据吗？

> 用户 2026-11-21 00:07 问："决策链这种方法是否科学且有证据？请你维护一下这个方法论本身，
> 并实时更新决策链地图。"
>
> 这是**用我们自己的证据纪律审视方法本身**——如果它经不起同样的审查，
> 它就是又一个"看起来合理但没证据"的构造，与幻觉引用无本质区别。

## 0. 结论先行（诚实版）

**这套方法是"半经验、半约定"的混合体**：

- **有真实证据支撑的部分**（可称"经验归纳"）：证据分级、四层判据、三次危机的免疫规则
- **我拍脑袋定的部分**（**无证据，是约定不是科学**）：三层汇聚的具体阈值"≥2"
- **有学术对应物但我们是独立发明的部分**：ADR、证据分级思想

**它不算"科学理论"**（不能预测什么决策会成功），但算**可审计的决策纪律**
（让每一步推理可追溯、可被证伪）——这个定位必须诚实标注，不能冒充科学。

## 2. 最诚实的一条：B2/B3 的"≥2"是我编的

用户原话是"**若干个**一般决策后的证据支撑"——中文"若干"是模糊量词，
我在写成 DECISION_CHAIN.md 时**自作主张量化为"≥2"**，并写进"判据"栏，让它看起来像硬规则。

这跟 agent 把"Aider 26→59%"编成"35B 不一致率 59%"是**同类错误的结构**：
把一个没有根据的数字包装成看起来精确的规则。

**处置**（本次维护）：
1. 把"≥2"从"判据"降级为"**经验阈值（默认约定，可调）**"，明确标注"非科学结论"
2. 说明它的实际作用：**防单点决策被当成架构决策**——这是它的价值，但价值≠科学有效性
3. 补一个反例说明阈值不是绝对的：K05（L5 永不做）我审核时只找到 2 条支撑，勉强达标——
   如果强行要求3条，这条真实重要的边界反而会被误判为"断链"。**阈值是工具，不是真理**

## 3. 这套方法"科学吗"——分维度回答

| 科学性的维度 | 判定 | 理由 |
|---|---|---|
| 可证伪性 | ✅ 有 | 每条断言都能被反例推翻（我们就是靠反例建的）|
| 经验基础 | ⚠️ 部分 | A1-A5 有本机反例；B2/B3 无 |
| 可重复性 | ✅ 有 | citation_guard/run_all 是机器判据，不是靠人记 |
| 预测力 | ❌ 无 | 它不能预测"哪个决策会成功"，只能审计"这个决策依据是否清楚" |
| 精确性 | ⚠️ 伪精确风险 | "≥2"和"E0-E5"的编号给人精确感，但阈值是人为的 |

**准确定位**：这是一套**规范性决策纪律（normative discipline）**，不是描述性科学理论（descriptive theory）。
它的价值是"让认知可审计"，不是"预测决策对错"。把它当科学理论会误用，当纪律则有效。

## 4. 外部学术对应（主代理 WebFetch 一手核实，2026-11-21）

| 我们的做法 | 学术对应物 | 核实结果 | 关系 |
|---|---|---|---|
| ADR 五段结构 | Michael Nygard, "Documenting Architecture Decisions", 2011-11-15 | ✅ **真实**（cognitect.com/blog 原文）| 我们用了 Title/Context/Decision/Status/Consequences 骨架；但原文的五段**没有 Evidence 强制段、没有决策层级、没有 Options 表**——这三样是**我们的扩展**（幻觉危机后加），不是 ADR 标准 |
| 证据分级 E0-E5 | Oxford CEBM Levels of Evidence (2011) | ✅ **真实**（cebm.ox.ac.uk 官方页；旧 URL 404 但站内导航可达正确页）| 思想同构（按证据强度分层）；但 E0=本机对照、E5=经验判断是**我们针对 agent 场景的定制**，不是医学分级 |
| "≥2 汇聚" | 无 | ❌ **找不到学术依据** | 纯自创约定（见 §2）|

### 关键权威引文（CEBM 官方，逐字）

> "no evidence ranking system or decision tool can be used without a healthy dose of judgement and thought."
> "The Levels is NOT intended to provide you with a definitive judgment about the quality of evidence."
> "The Levels will NOT PROVIDE YOU WITH A RECOMMENDATION."

**这权威地支持了我们的自审结论**：牛津 CEBM 自己说证据分级是 "short-cut"，不是 definitive judgment。
我们的 E0-E5 和"≥2 汇聚"也必须这样定位——**工具，不是真理**。任何把 E0 当"绝对正确"、
把"≥2"当"科学定律"的用法，都违背了这个权威警告。

### ADR 原文的额外收获

Nygard 原文说 ADR 的目的正是避免新人"blindly accept / blindly change"过去决策——
这与我们 `lineage/` 的动机完全一致。但原文也承认 ADR 只是 "early feedback quite positive" 的实践经验，
不是经严格验证的科学方法——所以 **ADR 本身也是工程实践，不是科学理论**。

**结论**：我们不是"发明了一套新科学"，而是**把已有科学组件按项目需要组合，并补了标准工具没有的两块
（决策主体、方案最优性）**——这两块是项目特有需求（用户明确要求），不是普适科学方法，必须如实标注。

额外发现：arXiv:2602.19466（Stanford/Anthropic/MIT, 2026）把 **Burden of Proof** 应用于 AI agent 决策授权——
与我们"关键决策需高等级证据"同构，但本次未逐字核实细节，**仅作方向性佐证，不写入判据**。

**两条关键改进**（来自交叉核实的诚实发现）：

1. **汇聚应看"独立性"而非"条数"**：Whewell/史学 corroboration 强调独立方法收敛，
   "3 个来源说同一句话"不如"2 个独立方法得出同一结论"。我们的"≥2 条"没写独立性要求——
   **这是方法论缺陷，已修**（见 §5 修订 4）。
2. **E4 用户拍板混入证据分级是概念混用**：E0-E3 是"证据强度"，E4 是"决策权归属"，
   ❌ 是"证据失效"——三者不是同一维度。医学分级里没有 E4 对应物。
   **已修**：E4 单列为"决策主体"维度（见 §5 修订 5）。

## 5. 维护后的规则修订（立即生效）

### 修订 1：阈值标注
`DECISION_CHAIN.md` §0 的"必须 ≥2"改为"默认经验阈值 ≥2（约定非科学，可因证据强度调整）"。

### 修订 2：新增"方法论自身的证据栏"
每个方法规则都要标"它自己是哪来的"——A 类反例 / C 用户指定 / 约定 / 逻辑演绎。
不许把约定写成判据。

### 修订 3：实时更新机制
本文件 + `DECISION_CHAIN.md` 是活文档：每次重大决策后同步更新
（本次已把"方法论自审"这个 K 决策记入 DECISION_LEDGER 与 CHAIN）。

### 修订 4：汇聚加"独立性"要求（学术交叉核实后新增）
"≥2 汇聚"改为"**≥2 条独立支撑**"——同一来源的重复陈述只算 1 条。
- 依据：Whewell consilience / 史学 triangulation——独立方法收敛才有证明力
- 反面：本次审计里"7 篇幻觉论文都说质疑有害"曾是 7 条，但同源同构（同一批编造），实际**独立性=0**
- 落地：DECISION_CHAIN 的每条汇聚，标注来源是否独立（本机实测 / 不同论文 / 用户拍板各算独立维度）

### 修订 5：E4 从"证据分级"移出，单列为"决策主体"维度
- E0-E3 = 证据强度（本机对照 → 本机实测 → 已核实论文 → 已核实社区）
- ❌ = 证据失效（幻觉/误用）——是 E0-E3 的否定，不是同级
- **决策主体**（用户拍板 / 用户+助手实测 / 用户+助手共创 / 项目所有者确认）是**另一维度**，见 DECISION_AGENCY.md
- 理由：医学证据分级里没有"患者拍板"这一级——把权力归属混进证据强度是概念错误
