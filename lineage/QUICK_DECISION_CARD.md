## 决策前三问（必须在回复里当场回答）

1. **什么层级？**
   - **G 一般**：参数/工具/单次开关
   - **I 重要**：机制/架构/协议 → 需 ≥2 条**独立**一般决策支撑
   - **K 关键**：身份/方向/根本架构 → 需 ≥2 条**独立**重要决策支撑
   - ⚠️ "≥2"是**默认经验阈值（团队约定，非科学定律）**——证据极强时 1 条 A 类链也够，证据弱时 3 条也不够

2. **什么证据？**（标注类型 + ID）
   - **A** 本机实测/对照（最强）· **B** 已核实外部（论文/社区）· **C** 经验判断（E4）
   - **❌** 幻觉/误用 = 禁用
   - **决策主体另标**：用户拍板 / 用户+助手实测 / 共创 / 项目所有者确认（这不是证据强度，是权力归属）
   - **铁律**：`listed`（只核了标题）不算 fully verified；引用必查 `config/citation_ledger.json`

3. **有哪些方案？**
   - 至少 2 个，各标代价/风险，说明为什么选这个
   - "说不出别的方案 = 没真正思考过"

## 四步动作（30 秒内可完成）

```
1. 判层级 → G/I/K
2. 查证据 → 台账 status 必须 verified/n-a；listed/partial 只能作背景
3. 列方案 → ≥2 个 + 选择理由
4. 记录   → I/K 级决策写进 lineage/DECISION_LEDGER.md（层级/证据/方案/日期/主体）
```

## 五条硬纪律（血泪换成）

1. **不因为结论合理就放宽证据**——我用真论文套错主张犯过两次
2. **证据假 ≠ 结论错**——降级为"未验证判断"，不翻案也不冒充正确
3. **汇聚看独立性不看条数**——7 篇同源幻觉 = 独立性 0
4. **分级是 shortcut 不是真理**——牛津 CEBM："no evidence ranking system... without judgement"
5. **agent 不独自拍板方向**——19 个 ADR 中 0 个纯 agent 决策
