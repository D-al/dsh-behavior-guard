# 工作契约：从对话纪律中沉淀的项目级规则

> 用户 2026-11-20 要求把"对话中反复强调的规则"变成项目资产。
> 来源：用户长期记忆 + 多轮对话中的明确纠正。这是项目级版本——运行时 agent 可读。

## 1. 子任务纪律（用户多次明确纠正）

- **派完后台子任务不要瞎等**：继续做不依赖它的独立工作；系统用完成通知主动呈递结果。
  **禁止 sleep 轮询 / 反复空查 TaskOutput**——这是浪费。
- **想看进度先直接查一轮**，不要预设"还没完成"就 sleep 等待。用户 2026-11-20 两次纠正此点。
- 能并行的活一律派子任务（用户多次强调"一旦发现可以并行就直接派"）。

## 2. 方案沉淀纪律（用户 2026-11-19 明确）

- 每次规划/调研/方案磋商，**结论必须写进项目活文档**（ROADMAP.md 是主入口）或结构化知识资产
  ——不能只停留在对话里。
- **被证伪的方向也要记录**（避免重复踩坑），写进 `lineage/` 或"明确不做"清单。
- 判据：如果一个结论下次会话还要重新推导一遍，它就该进项目。

## 2.5 决策标记纪律（用户 2026-11-21 明确）

**从今以后，做每个决策时当场标记三件事**（不是事后补）：

1. **决策层级**：
   - **一般决策 G**：参数值、工具选择、单次开关（证据=单点实测或已核实引用）
   - **重要决策 I**：机制/架构/协议——**必须 ≥2 个 G 汇聚 + ≥1 个 A 类实测**
   - **关键决策 K**：身份/方向/根本架构——**必须 ≥2 个 I 汇聚 + 至少一条链来自 A 类地基**
2. **证据**：每条证据标类型（A本机实测/B已核实外部/C经验判断(E4)/❌幻觉禁用；决策主体另标(用户/共创/agent)）+ 证据 ID（台账或实测出处）
3. **方案**：列 ≥2 个考虑过的方案 + 各自的代价/风险 + 为什么选这个（见 ADR 模板 Options 段）

**判据**：如果一个决策说不出"考虑过哪些别的方案"，说明它没被真正思考过。
**层级不足的证据汇聚 = 断链**，必须补证据或显式降级，不许悄悄跳过。

## 3. 证据纪律（2026-11-20 三次危机后）

- 任何外部引用进决策前，必须在 `config/citation_ledger.json` 登记且 status=verified/n-a。
- **"编号真实"只过 L1**——必须逐层核到标题/结论/数字（见 EPISTEMOLOGY.md）。
- 抓取失败标"待核"，不默认通过；真论文也可能被误用（我犯过两次）。
- 写决策走 `decisions/_ADR-TEMPLATE.md` 的 Evidence 段，`citation_guard` 机器校验。
- **"已核实"标签只能在核实动作完成后打**（2026-11-21 新增）：不许先写"已核实"再补核实。
  子任务结果没拿到就明说没拿到，去实际核实，不能凭记忆填——我犯过一次（见 METHODOLOGY_AUDIT §5.5）。
  注意 `citation_guard` 只查论文引用，**方法论依据、心理学研究、事故案例不在它的覆盖范围**，只能靠这条纪律。

## 4. 工具与身份边界

- dsh 权限弹窗交给 `dsh-approval-delegate` 插件，不打断用户手工点；高风险留给本人。
- **不加 MCP**（dsh 不支持）；工具面 28 个已在风险区，收敛是用户拍板项（M5）。
- **agent 不独自拍板方向**——19 个 ADR 中 0 个纯 agent 决策（见 DECISION_AGENCY.md）。
- L5 自我改写目标永不做（A5 caveat）。

## 5. 交付与验收纪律

- "文档宣称完成" ≠ "代码实际生效"——三层交叉验证（运行版 trace + 真实日志 + 产物 mtime）。
- 别用聚合 util% 判断推理活性——用 token 连续采样（单帧误判教训）。
- present 前必须过深检（import/占位符/编码/重复段落/路径/交付物）。
- 说"全绿/已推送"前核对远端/权威/运行版三处 commit+sha256。

## 6. 可逆性纪律

- 破坏性操作前建可逆点；删 junction 用 `fsutil reparsepoint delete`，绝不 `Remove-Item -Recurse`。
- 个人目录（Desktop/Downloads/Documents/Home）的清理是高危区：先扫描列清单、确认后再动。

> 本契约随用户新规则更新；更新要同步到 `~/.workbuddy/MEMORY.md`（用户级）与本文件（项目级）。
