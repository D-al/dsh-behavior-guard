# 认识论：我们如何知道，以及在哪里犯过错

> 这是认知谱系的"证据理论"层——回答"什么算证据、如何验证、我们历史上在哪里被骗过"。
> 与 `docs/CITATION_AUDIT_PROTOCOL_20261120.md`（技术协议）互补：那里是操作手册，这里是信念来源。

## 1. 证据分级（从强到弱）

| 级别 | 类型 | 判据 | 例子 |
|---|---|---|---|
| **E0** | 本机对照实验 | 同机同模型 A/B、多轮取中位、独立验收 | 温度 0.7 vs 0.1/0.9（U 形曲线）；moe-cache-cpu-share 证伪 |
| **E1** | 本机实测（单次/少次） | 真实 trace/事件/产物，非推测 | read→write 转化 18.2%；write 0% 失败率 |
| **E2** | 已核实外部论文 | 四层判据 L1-L4 全过，摘要支持结论 | RoPE 复制缺陷（2607.16072）、Diff-XYZ（2510.12487）|
| **E3** | 已核实社区实践 | 官方博客/issue 原文核实 | Anthropic 10+ tools、Claude Code #26996 |
| **E4** | 经验判断 | 无证据，基于风险偏好的默认选择 | ADR-0014 撤销强制二选一（降级后）|
| **❌** | 幻觉/误用 | 编号真但内容假，或真论文不支持该主张 | 18 篇幻觉 + 6 篇误用（见引用审计）|

**⚠️ 2026-11-21 方法论自审修订**：原 E4=用户拍板已从证据分级移出——
"决策主体"（用户拍板/共创/agent执行）是**另一维度**，见 `DECISION_AGENCY.md`；
把权力归属混进证据强度是概念错误（医学分级里没有"患者拍板"这一级）。原 E5 顺延为 E4。

**铁律**：决策的依据级别必须显式标注；E4 不许冒充 E0；❌ 不许作为依据。

> **工具定位（牛津 CEBM 官方权威表述，2026-11-21 WebFetch 核实）**：
> "no evidence ranking system or decision tool can be used without a healthy dose of judgement and thought"
> "The Levels is NOT intended to provide you with a definitive judgment"
> 分级是 shortcut 不是真理——E0 不代表绝对正确，仍需连续采样等纪律。完整自审见 `METHODOLOGY_AUDIT.md`。

## 2. 三次认识论危机（我们的"认知免疫系统"是怎么长出来的）

### 危机一：单帧误判（2026-11-18/20）
- **现象**：看到 nvidia-smi 聚合 util 100%、read 循环，判定"GPU 卡死"
- **真相**：用户实证两窗口推理正常（n_decoded +145/5s）；聚合 util 骗人，推理走 Copy 引擎
- **纠正**：判据改为 **token 连续采样**，绝不单帧 util%（DIAGNOSIS_CORRECTION_20261120.md）
- **免疫**：所有"活性"判断必须连续采样 ≥2 次

### 危机二："文档宣称完成 ≠ 代码实际生效"
- **现象**：合并包 v2.0.0 宣称修了 verify-on-stop，实测 trace 里只有 s1 单测假数据
- **真相**：9666 行 trace 中 89% 是测试 sid，真实会话仅 883 行
- **纠正**：证据分层——只认真实 sid 的 trace / 独立产物，禁止关键词计数
- **免疫**：三层交叉（运行版 trace + 真实日志 + 产物 mtime）

### 危机三：批量幻觉引用（2026-11-20）
- **现象**：7 篇 arXiv 编号真实但标题结论全编造，驱动了 ADR-0014 决策；
  全项目审计后又发现 11 篇 + 6 篇误用
- **纠正**：四层判据 L1-L4 + 官方 API 直连 + citation_guard 机器守卫
- **免疫**：`config/citation_ledger.json` + `tools/citation_guard.py` + ADR Evidence 段

## 3. 一个尚未解决的元问题：真论文也可能被误用

我们查出的错误分两类：
1. **假证据**：编号真、内容假（18 篇）——靠 L2 标题比对能抓
2. **真证据误用**：论文真，但用它支撑它不支持的主张（如 ICLR2024 自纠错论文被说成"质疑有害"；
   JudgePanel 支持好 judge 被写成"否决多 judge"）——**L2 抓不到，必须读 L3 摘要**

第 2 类更危险，因为它能通过"标题核对"这一层假象。我们自己的纠错（用真论文替换假论文）
也犯了一次同类错误——这证明**核实者也会犯错**，所以机制（guard）比自觉更可靠。

## 4. 证据使用的三条纪律

1. **不因为结论合理就接受证据**——这是我 2026-11-20 犯的错（"决策对所以证据可以宽一点"）
2. **不因为论文真就接受数字**——摘要没有的数字标"正文未核"
3. **证据假 ≠ 结论错**——假证据只能说明"未被证明"，不能反推结论相反；
   处理方式是降级为"未验证判断"，不是翻案

## 5. 与身份的关系

一个人的身份不只是"做过什么"，而是"**在什么证据下做了什么选择，以及发现证据假时怎么改**"。
上面三次危机塑造了我们：从"看 util 猜状态"到"连续采样"、从"看关键词判完成"到"证据分层"、
从"信引用"到"四层核实"。这些纠错本身，就是"我是谁"的一部分。
