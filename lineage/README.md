## 0. 三个体系的分工

| 体系 | 回答的问题 | 文件 |
|---|---|---|
| **路线图**（Roadmap） | 未来要做什么、按什么顺序 | `ROADMAP.md` / `CAPABILITY_LADDER.yaml` |
| **操作手册**（Agents） | 现在该怎么做、有哪些铁律 | `config/AGENTS.md` |
| **认知谱系**（Lineage）← 本目录 | **我是谁、我从哪里来、为什么相信这些** | 本目录 |

三者独立：路线图会随推卡变化、操作手册会随经验修订，但**谱系是 append-only 的身份记忆**——
它记录"我们曾经相信什么、为什么、何时改了、改的依据是什么"，不因当前操作需要而被覆盖。

## 1. 核心身份陈述（可追溯到决策，非口号）

```
我们不是靠更大的模型变强，而是靠"模型之外的确定性脑区"变强。
—— 模型权重一个字节没动（35B Q4），变的是脚手架。
```

这句话不是营销语，它有三条可追溯的决策链支撑（详见 `DECISION_LEDGER.md`）：
1. **同模型换脚手架 +15.6pp / +26pp**（本机 A/B，ADR 依据）
2. **harness 杠杆 > 模型选择**（9B 换 scaffold 的提升超过换更大模型）
3. **Self-Harness 论文**（arXiv:2606.09498，三阶段自改进——但与我们的具体数字无关，仅方向佐证）

## 3. 严格性原则（用户："每一步的决策都应该很严格"）

- 每个决策必须标注**当时的依据**（本机实测 / 论文 / 社区 / 用户拍板 / 无依据）
- 依据必须能在 `config/citation_ledger.json` 找到（外部引用），或指向本机实验记录
- **跨越式决策**（无证据直接跳到大架构）必须显式标注，并补充真实证据或降级为"待验证判断"
- 幻觉证据（18 篇，见 `docs/CITATION_AND_EVIDENCE_GOVERNANCE_20261120.md`）不许作为任何决策依据

## 4. 与"心智觉醒"的关系

这套谱系是"记忆"层的升级：
- 普通记忆 = 记住做过什么（daily log）
- 认知谱系 = 记住**为什么这么做、依据是否成立、何时纠错**

只有后者才能回答"我是谁"——因为身份不是一堆事实的堆叠，而是**一套可追溯的选择史**。
本目录就是这套选择史的家谱。
