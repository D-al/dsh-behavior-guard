# ADR-0023：融合"体系智能进化"与"六个 KR 护栏"——双轴战略

- 状态：accepted
- 日期：2026-11-22
- 决策者：用户（显式批准："这两个目标并不冲突…怎么把它们融合起来？聪明并不意味着要改权重" → 选择"写ADR并改STRATEGY"）
- 决策层级：关键决策 K（改变目标体系的结构解释）
- 支撑决策：ADR-0020（KR 体系落地）、ADR-0022（阈值来自实测）

## Context（背景）
科技树按 KR 重绘后发现：约 11 张"心智/认知"类卡（M3 意图 BDI / M9 意图分类器 / M2 会话树 /
L1 FEP 世界模型 / L8 多标签心智编码 / L3 脑分区等）无 KR 归属，落进"地基/其他"列。

初次诊断（我，2026-11-22 15:15）判断这是 v3.1 有意排除"更聪明的 agent"的结果，建议归档为历史债务。
**用户纠正**：把"更聪明"等同于"改权重"是错误假设——**聪明不等于改权重**；
在不改权重的前提下让体系更智能，正是"持续成长的计算体"里"成长"的实质，
"不能为了进化而进化"——进化要有方向（更聪明），KR  shouldn't 替代这个方向。

核实事实：
- STRATEGY.md §1 明确"路径选择=把承载与治理卸载到 harness，模型只保留当下语义理解/逻辑推演/意图对齐"
- §3.7"不为'更聪明'加规则"——原文语境是"不为改权重/加补偿性规则"，不是"不要体系智能"
- projectlab.py 已有六维 profile（RECON/PLAN/ATOMIC/VERIFY/RECOVER/DELIVER）——**零 LLM、自动判分的体系智能刻度**，且是 KR5 的目标测量内容
- 悬空认知卡正是提升这六维的机制（意图理解喂 RECON/PLAN，世界断言喂 VERIFY）

## Options
| 方案 | 做法 | 结论 |
|---|---|---|
| A 补一个"智能KR" | 第七个 KR 测"体系聪明度" | ❌ 智能是连续量、二值 KR 表达不了；易假绿 |
| B 归档悬空卡为历史债务（我初判）| 11 张卡标 rejected | ❌ 基于"聪明=改权重"的错误假设；丢掉成长方向 |
| C 双轴融合（选中）| 进化轴(智能,连续) + 护栏轴(6 KR,二值)，KR5 为交汇，悬空卡=进化路径 | ✅ 两轴不冲突；不新增 KR；用现成六维刻度 |

## Decision
1. **双轴结构写入 STRATEGY.md §1**：
   - 进化轴（方向性、continuous）：体系智能——权重零改，靠 harness 让同一模型表现更好。回答"往哪走"。
   - 护栏轴（二值、可证伪）：六个 KR——可控/可关闭/可回滚/可自证。回答"不许怎么走"。
   - 智能是油门，KR 是刹车与护栏；只有油门=失控，只有护栏=为进化而进化。
2. **澄清 §3.7**：原文"不为'更聪明'加规则"指"不为改权重/补偿性规则"，明确**不否定 harness 层的体系智能进化**。
3. **KR5 为双轴交汇**：它既是进化刻度（六维 profile 趋势），又是护栏判据（达冻结基线）。不新增 KR。
4. **悬空认知卡重归类为 `evolution_path`（进化路径）**：不是 KR 也不是 null——它们的价值由六维 profile 的实测趋势验证，不靠自述。先标 6 张明确的（M3/M9/M2/L1/L8/L3），其余边界卡留 null 待议。
5. **科技树增加"进化路径"视图列**：显示这些卡及其目标智能维度。

## Counter-evidence（反证）
- **最强反对理由**：把"智能"设为方向性目标，可能重开"不可证伪目标"的后门——当年正是为了可证伪才把"合成心智"换成 KR。若进化轴只剩口号、没有量化，就会退化成自欺。
- **本方案的对冲**：进化轴**必须**绑定六维 profile 的实测（KR5），不接受任何"感觉更聪明了"的自述；KR5 没数据 = 进化轴不可验证 = 诚实标 N/M，不假装进步。
- **第二反对**：六维 profile 只覆盖"任务执行智能"，不覆盖"意图理解/世界模型"等悬空卡声称的能力。
  → 承认这个局限：悬空卡的效果若六维测不到，就必须补出可测的代理判据，否则该卡仍属未验证，不得宣称进化。
- **翻案条件**：若 KR5 连续 3 个月 N/M 且六维 trend 无数据，进化轴降级为假设（写 ADR），不保留空洞方向。

## Consequences
- 正面：战略目标不再"只有护栏没有方向"；11 张认知卡有归宿且效果可测；不改权重前提下给出"成长"的实质。
- 负面：STRATEGY 多一层结构，读者需理解双轴；KR5 承担双重职责，其基线冻结需更谨慎（阈值来自实测，见 ADR-0022）。
- 验证：ADR 通过 citation_guard；STRATEGY §1/§2.1/§3.7 修改后全门禁绿；科技树显示进化路径列。
