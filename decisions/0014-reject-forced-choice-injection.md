# ADR-0014：撤销强制二选一注入

- 状态：supersedes 旧的"强制 A/B 决策"注入
- 日期：2026-11-18
- 决策者：用户 + 助手

## Context
v2.7.0 上线"检出重复→强制二选一"。后续调研发现压倒性反面证据："Are you sure?" 与 "You are wrong" JS 散度仅 0.0186；条件提示让 Llama-3.1-8B -20.4pp / GPT-4o -20.9pp，76.6% 正确答案被推翻。

## Decision
改为**中性事实陈述 + 退出许可**：陈述"这些动作已执行过、结果在上下文中"，给"可直接结束或选不同动作"，不质疑、不暗示未完成。

## Consequences
- 避免诱发答案摇摆（正是现场"写完又重做"症状的机制同源）
- 教训：注入信息应进决策/路由层，不应进答案生成层去强迫翻转
- 测试：test_mind_state.mjs T1b 专门验证"无质疑式二选一"
