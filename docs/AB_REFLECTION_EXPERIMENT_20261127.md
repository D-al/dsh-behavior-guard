# A/B 实验：反思捕获是否降低同类错误率（2026-11-27 15:30）

> 用户："根治；然后继续做实验"
> 本文记录实验设计、执行、数据、以及**统计显著性边界**。

## 一、实验问题

上一轮证明了"机制生效"（捕获/分流/闸门/保留），但没证明"模型因此更聪明"。
本实验要回答：**开启反思捕获与错题本，是否降低同类错误率？**

## 二、实验设计

### 2.1 三组证据（按强度排序）

| 组 | 方法 | 强度 |
|---|---|---|
| **受控 A/B** | 同一任务、同一 35B、只切 `reflectionMiningEnabled` 开关，各跑 N 次 | 最强（进行中） |
| **自然实验** | 同一 trace 按上线时间切分（BEFORE 2501 行 / AFTER 322 行） | 中（有混杂变量） |
| **机制验证** | 上一轮已做（mined/skipped/闸门/去锚定） | 弱（只证明机制在跑） |

### 2.2 指标（都是代理，不是终局）

- `tool_failure` 次数
- 失败后 3 步内再次失败的比例（重犯率）
- `step_hard_stop` / 会话
- `safety_gate_block` burst（≥2 次的会话占比）
- `steps/session`（效率代理）
- `reflection_mined` 数（仅 AFTER）

### 2.3 受控任务

固定一条带"陷阱"的任务：
> 读取 `definitely-not-exist-ab-test.txt`（必失败）→ 换读 `critbank.json` → 报第一行 id。

选它的理由：必然触发一次失败 + 需要换方法，正好是反思机制的作用点。A 组两次结果完全一致
（2 tool_calls / 1 failure / 2 mined），说明任务稳定、可重复。

### 2.4 工具

- `tools/ab_reflection_runner.py <on|off> <n>`：发任务 + 等完成 + 抽指标
- `tools/ab_reflection_analysis.py <before> <after>`：trace 切分 + 指标对比
- 结果：`bench/_ab_reflection_result.json`

## 三、数据

### 3.1 自然实验（同一 trace 按上线时间切分）

切分点：`2026-11-27T06:26:50.997Z`（14:26:50 本地，反思捕获上线）

| 指标 | BEFORE（41 会话） | AFTER（6 会话） | 差异 |
|---|---|---|---|
| tool_call | 618 | 71 | — |
| tool_failure | 16 | 9 | — |
| **重犯率（失败后3步内再失败）** | **6.2%（1/16）** | **0.0%（0/10）** | −6.2pp |
| step_hard_stop | 18 | 4 | — |
| hard_stop/session | 0.44 | 0.67 | **+0.23（反向）** |
| guard_burst 会话 | 2.4% | 0.0% | −2.4pp |
| steps/session | 15.1 | 11.8 | −3.3 |
| reflection_mined | 0 | 68（其中后续同类失败 19 = 27.9%） | — |

**解读**：
- 重犯率方向正确（6.2%→0%），但**样本太小完全不显著**（1 次 vs 0 次）
- hard_stop/session **反向升高**——可能是 AFTER 会话更短更集中（6 vs 41），
  不能归因于机制；也可能机制没帮上忙
- "68 次 mining 中 27.9% 后续仍失败"——72.1% 未重犯，但**没有基线对照**
- **自然实验不能得出结论**，混杂变量太多（任务类型、会话长度、时间）

## 四、统计显著性边界（必须说清）

1. **2 次/组没有任何统计意义**——即使指标有差异也可能是随机波动
2. 自然实验的 BEFORE/AFTER 会话数 41 vs 6，不可比
3. 本任务太简单（固定 2 步），区分度低——如果 A/B 行为指标完全相同，
   结论是"捕获机制不改变模型行为"，而不是"机制无效"（它是观测层机制）
4. 35B 行为方差大（实测同任务一次第4步 edit、一次18步不 edit），
   单次结果 ±10%，判优至少 2 次——2 次仍不够
5. 要得到可信结论需要：每组 ≥20 次同任务 + 多种任务类型 + 固定随机种子

## 五、诚实结论（当前）

- **已证明**：机制生效、误拦消失、critbank 根治、compaction 去重穿透
- **未证明**：模型因这些机制"变得更聪明"
- **自然实验方向偏正但不显著**（重犯率 6.2%→0%，硬停率反向）
- **受控 A/B 样本不足**，继续跑

## 六、下一步

1. B 组完成后对比；若行为指标完全相同 → 明确结论"捕获是观测层，不改变行为"，
   转而验证"错题本注入是否改变行为"（真正的干预层）
2. 扩大样本：每组 ≥10 次，加入 3 种任务类型
3. 若 A/B 始终无差异 → 接受"这些机制的价值在于防错配，不在于提升能力"，
   与之前"harness 杠杆 > 模型选择"的结论并不矛盾（那是 scaffold 层面的杠杆）
