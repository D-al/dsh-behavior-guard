## 1. Vision（修正表述，遵守公开库纪律）

> **在本机持续建设一个可靠、可成长的计算体：能感知环境、采取行动、从经验中改进自身，
> 在固定可验证任务集上稳定达到预设能力基线，并始终处于人类可理解、可关闭的边界内。**

**v3→v3.1 表述修正**：
- "不断逼近人类专家水平" → "在固定可验证任务集上稳定达到预设能力基线"
  （去掉能力夸大类表述，与刚加的 AGENTS.md"对外文书表述纪律"对齐；
  "预设能力基线"由人类标定，不是系统自封的"专家水平"）
- 其余保持方向性、aspirational、不验收

**构念声明**：不声称意识/主观体验/生物自维持；四面向必要非充分；能力声明必绑任务域。

### 判定权归属（v3 缺失，v3.1 补）
- **KR 通过与否不由 agent 自判**——每条 KR 指定判定者（外部脚本 / 人类抽样）
- agent 可提供证据，但**不得判定自己达标**（防自认证 Goodhart）
- 判定结果写入 append-only 日志；争议由人类裁决

### KR5 矛盾修正
v3 的 KR5 "阈值待标定却列 committed" 自相矛盾。v3.1 明确：
**基线由人类冻结后才生效；未冻结期间 KR5 不参与达标判定**，不产生"待定"灰色状态。
