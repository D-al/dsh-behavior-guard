## 一、量化映射与公式推荐

### 推荐映射表

**收益等级 → 数值：**
- 低 = 1
- 中 = 2
- 中高 = 3
- 高 = 4

**成本等级 → 数值：**
- 低 = 1
- 中低 = 2
- 中 = 3
- 中高 = 4
- 高 = 5
- 极高 = 6

### 推荐公式：**性价比 = 收益³ ÷ 成本**

**理由：**
1. **为什么用除法？** "性价比"本质就是每单位成本换来的收益，收益/成本是最直觉的定义。
2. **为什么收益要三次方？** 这是关键设计——把"绝对高收益"的价值放大。如果只用线性比，一张「高收益+高成本」卡（4/5=0.8）和一张「中收益+中高成本」卡（2/4=0.5）差距不大；但用三次方后（64/5=12.8 vs 8/4=2），高收益卡的权重被显著拉开，符合业务直觉：有些事虽然贵但值得做。
3. **为什么不成本取幂？** 成本已经是六级阶梯（1~6），惩罚力度已经足够；再取幂会导致极端值失控。

## 二、拓扑序 + 性价比的结合算法

### 推荐算法：**加权拓扑排序（Topological Sort with Priority Queue）**

核心思路：**不是先排好拓扑序再替换，而是用 Kahn 算法的变体，在每个阶段从"已解锁节点"中选性价比最高的。**

```
算法步骤：
1. 建图：计算每个节点的入度（依赖数）
2. 初始化一个优先队列 PQ，把所有入度为 0 的节点放入
   - 队列按性价比分数从高到低排序
3. while PQ 非空:
     a. 弹出 PQ 中性价比最高且入度为 0 的节点 N
     b. 将 N 加入最终排序结果
     c. 对 N 的每一个后继节点 S：
        i. 把 S 的入度减 1
        ii. 如果 S 的入度变为 0，将 S 插入 PQ
4. 如果最终排序长度 < 总节点数 → 存在环，报错
```

### 冲突处理规则：

> **依赖优先于性价比。** 如果卡 B 依赖卡 A，即使 B 的性价比远高于 A，A 也必须排在 B 前面。

这正是上述算法天然保证的性质——B 只有在 A 被弹出后入度才归零，才会进入候选池。

## 三、特殊卡的修正因子与例外规则

你提到的三张卡确实是纯公式的盲区，建议加以下规则：

### 1. L7「探索、不占坑」→ **独立通道 + 豁免规则**

L7 按公式得分是 8（高），会被排得很靠前，这其实是对的——它确实应该优先做。但标注"不占坑"意味着它的**优先级不应挤占正式迭代的名额**。

**规则：** 设立一个"探索层"，所有标记为"探索/降级/观望"的卡片单独列出，不计入正式路线图排序。它们可以并行做，但不占用每个迭代的 capacity。

### 2. A2-A5 自治阶梯链 → **强制链接约束**

A 系列不是自由选择问题，而是硬性依赖链：`A1 → A2 → A3 → ... → A4(A3_5) → A5`。其中 A5 还依赖前面全部。

**规则：** 对这种强链，不使用 PQ 比较，而是用 `GROUP` 方式锁定相对顺序——链内顺序不可变，只有整条链与其他节点的先后关系才参与 PQ 调度。具体来说：
- A2 在 A1 后 earliest 可以做
- A3 必须在 A2 之后
- A4 必须在 A3_5 之后  
- A5 必须等 A1,A2,A3,A3_5,A4 全部完成后才能开始

这意味着 A5 **无论如何都会被推到很后面**，即使它的性价比还行。这是正确的——它依赖太多前置工作。

### 3. L1「最后做」→ **硬约束而非软分数**

L1 收益高(4)、成本极高(6)，按公式得 10.67，差点排第二。但备注明确说"最后做"且依赖 M1,M3,M9。

**规则：** 
- **依赖已经是硬约束**：M3 和 M9 都排在 L1 前面，所以依赖链条天然把它推后了。
- **"最后做"是业务决策而非排序结果**——应设为 **max_position = N（最后一个位置）** 的硬性上限，而不是靠性价比决定。

**更好的做法：** 对于标注"最后做"或"压轴"的卡，直接设一个**最晚位置约束**。拓扑排序完成后，如果该卡在最终序列中的位置早于约束位置，将其移到约束位置并重新调整中间节点。

## 五、这个方案最大的弱点

**核心弱点：收益和成本的量化本身带有高度主观性。**

你的评级（"中高""中高""低"等）是定性描述，转换成数字时存在两个问题：

1. **"中=2, 中高=3, 高=4"之间的间距是否相等？** 从业务角度看，从中到高可能比从低到中的价值跃迁更大。如果是这样，应该用非线性映射比如 `低=1, 中=1.5, 中高=2.5, 高=4` 或者对数映射。目前线性映射可能低估了"高"的价值。

2. **成本的主观判断偏差：** "高"和"极高"在数值上只差 1 分（5 vs 6），但实际投入可能是 2 倍甚至更多。如果成本是指数级增长的，那线性成本映射就会严重低估极高风险卡片的代价。

**建议改进方向：** 如果可能，让每个卡的负责人给一个**量化的 effort estimate**（人天或故事点数），而不是仅靠定性评级。定性→定量的转换容易失真，定量数据才能支撑更精确的排序决策。
