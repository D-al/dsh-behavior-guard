# 调优决策链（蒸馏版）

> 每条含"当时判断 → 证据 → 结果"。完整 ADR 格式见 [decisions/](../../../decisions/README.md)。

---

## 1. n-cpu-moe 40 / cache 2736 —— 用户坚持复测导致的翻案（10-27）

- **当时判断**：初测 40/2736 预填充 1034、解码 59.34，被误判为"系统偏暖噪声"，暂留 41/3072
- **证据**：用户坚持复测 → 两个独立会话证明 40/2736 预填充稳定 **1019-1034**，41/3072 稳定 **569**（三次测量 556/569/569）
- **结果**：**判断翻转**，采用 40/2736。预填充 +79% 是真实配置效应
- **沉淀铁律**：单次测量不能判"持平"；异常见效必须复测两个独立会话

## 2. 整层挪 GPU —— A/B 证伪（10-27）

- **假设**：n-cpu-moe 41→39（2 层专家整层挪 GPU）+ cache 3072→2400，显存账净 +8MiB
- **证据**：解码 **51.4** vs 基线 58.07（**-9.5%**）
- **结果**：否决。机理：减缓存让剩余 39 层热专家回退 DDR4，损失覆盖 39 层 >> 挪 GPU 的 2 层

## 3. 预填充"卡死"归因翻案 —— 采样器抓现场（11-06）

- **当时判断**：显存换页 / `--cache-ram` 导致卡死
- **证据**：debug 日志 `slot encode_mtmd_:` 后 **41 秒**才解码；GPU 0-6% / 16W / CPU 1.4 核；关掉 cache-ram 照旧复现
- **结果**：真因是视觉编码器在 CPU（141s/张）→ `MMPROJ_OFFLOAD=1`
- **沉淀铁律**：采样器抓现场 > 猜归因

## 4. 中文锚点措辞 —— 一个字毁掉整轮（11-07）

- **当时**：`{{- '嗯，' }}`（自述句）成功 → 改成命令句
- **证据**：命令句触发"只输出好"回路；回滚后重放 2 次正常
- **结果**：锚点必须是**自述句，不能是命令句**。生成位置的锚点一个措辞决定整轮成败

## 5. moe-cache-cpu-share —— 最重要的证伪（11-18）

- **假设**：`--moe-cache-cpu-share=1.0` 让 decode **+37%**，看似纯赚
- **证据**：端到端 P5 基准**慢 2.4 倍**（每步增量 prefill 慢 4-5×）
- **结果**：生产保持 0。**确立铁律：decode t/s 是误导性指标，加速必须端到端验证**

## 6. 温度 U 形（11-10）

- 0.1 想完不干（683 字计划后 EOS）；0.9 草率收工；**0.7 在 P3/P4/P5 三项 2/2 且最快**
- 结论：温度是主导变量（> 量化档位）；`.env` 的 LLAMA_35B_TEMP 必须留空

## 7. 4B 不是轻量档（10-14）

- 干净冷启：qwen3:8b 冷 6.9s/热 12.6s；qwen3:4b 冷 **56.7s**/热 27.9s
- 根因：Qwen3-4B 原生 256K 上下文、KV 开销大。参数量 ≠ 延迟

## 8. q8_0 KV 破 32K OOM（10-19）

- fp16 KV 在 32K 时 8GB 卡加载即 OOM → `q8_0 KV + Flash Attention`
- VRAM 峰值 7519/8188MB 通过，17.24 t/s；后被 35B 配置继承

## 9. SearXNG 替换内置搜索（10-16）

- 内置 provider 需外网/key；自定义 provider 走本地 SearXNG
- 曾试禁用 tool-web：连带 web 服务坏且实际没移除 → 放弃该路

## 10. llama-server 选型（10-19）

- 单用户 Windows 首选 llama.cpp 主线（原生 CUDA、OpenAI /v1 drop-in）
- vLLM/SGLang 需 WSL2 且单用户更慢；LM Studio 仅 GUI 备选
