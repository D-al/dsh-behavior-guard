## 蒸馏原则（社区大项目做法）

原始日志（逐日、流水账、含失败与试错）→ **历史说明书**（按主题、只留决策与结果）→ README（一句话结论）。
三层各司其职：
- 原始日志：完整的试错过程，不可删（逢疑可查）
- 本目录：提炼后的"发生了什么、为什么、结果如何"
- README/ADR：结论与不可变决策
